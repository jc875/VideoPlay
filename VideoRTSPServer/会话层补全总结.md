## 三、本轮顺手修的编译问题(如实记录)

| 问题 | 现象 | 修复 |
|---|---|---|
| 文件编码 | 我写入的文件 UTF-8 无 BOM,MSVC 按 GBK(936)读,中文注释把花括号解析错乱 C2447 | 源文件加 UTF-8 BOM |
| `inet_addr` 弃用 | VC2026 把旧 Winsock API 当错误 C4996 | 两个 .cpp 顶部 `#define _WINSOCK_DEPRECATED_NO_WARNINGS`(include winsock 前) |
| `sscanf` 不安全 | C4996 | `#define _CRT_SECURE_NO_WARNINGS` |
| **sscanf 可变参数不隐式转换** | `%s` 传 Buffer 没强转 → sscanf 会把对象内存当缓冲区写(UB) | 显式 `(char*)method/url/version/seq` |
| `buffer[i]` 重载歧义 | Buffer 有 `operator char*()`,`[]` 和内置指针下标竞争 C2666 | 改用 `buffer.at(i)`(参考版同款) |
| `std::shared_ptr` 未 include | Socket.h 用 shared_ptr 但没 `<memory>`,部分 TU 报 C2065 m_socket 未声明 | Socket.h 补 `#include <memory>` |
| `ws2_32.lib` 未链接 | 全部 Winsock API LNK2019 | Socket.h 加 `#pragma comment(lib, "ws2_32.lib")` |
| `ETRACE` 多重定义 | EdoyunThread.h 头文件定义非 inline 函数,两个 TU 各一份 LNK2005 | 改 `inline void ETRACE` |

⚠️ **遗留小坑(未处理,如实报)**:
- `EdoyunThread.h` 的 `Stop()` 里 `if(m_bStatus = false) return true;` 是赋值不是比较(笔误,行为恰好正确但语义错,建议改成 `==`)。
- `Socket.h`/`CEdoyunQueue.h` 中文注释仍 C4819 警告(无 BOM 的 UTF-8),不影响编译,后续可统一加 BOM。
- `sscanf` 写 `std::string::c_str()` 是教学写法(参考工程同款),严格是 UB,正式项目应换 `std::vector<char>` 或 `std::string::data()`(C++17)。
